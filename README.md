# IB Atlas · Personal IB Tracker

个人 IB Diploma 学习工作台，部署到本仓库的 **GitHub Pages**。黑白灰单色响应式界面，无运行时框架依赖。开发时使用轻量脚本生成单个浏览器脚本，已提交的 dist/ 可直接运行。

## 功能

- 考试冲刺：考试日期、范围、目标与倒计时，生成三步复习任务并关联成绩
- 每周复盘：回顾实际学习数据、记录收获与调整，将下一步转成任务
- 错题本：记录题目、原思路、订正、原因、重做与掌握状态，可生成关联复习任务
- 学习分析：近 7 / 30 / 90 天的时长、活跃日、最长连续天数、学科分布、测评与错题原因
- 本地全局搜索：按关键词及类型查找记录、分页并直接打开编辑
- 每周学习计划、每周目标、计划完成后记录实际学习时间
- 独立复习中心，按自评安排 1 / 3 / 7 天后的复习，支持撤销
- 个人学习资料库：笔记、链接、科目与类型筛选、星标
- 六张可收藏与编辑的学习工作卡：主动回想、错题、周复盘、证据分析、模型、研究问题
- 今日行动首页：待办、到期复习、快速记录与首次使用引导
- 手机底部快捷导航、更多导航菜单、键盘可访问的操作
- 六大学科组、HL / SL、自定义课程与目标成绩
- 科目详情：知识点、未开始 / 学习中 / 待复习 / 已掌握、复习日期、笔记、学科任务与成绩
- 掌握进度：添加知识点后，根据已掌握比例自动计算；未添加时保留手动进度
- 任务增删改、完成状态、截止日期、优先级、科目与状态筛选
- 今天 / 近 7 天 / 逾期快捷筛选、结果计数和清除条件
- 删除记录后可立即撤销，其他操作与新增记录不会被撤销覆盖
- 学习日程：月历与清单切换，汇总任务、学习计划、考试与核心项目，支持筛选和按日添加
- 学习日志、学习时长、最近七日统计
- 成绩与反馈、分科成绩趋势、目标对照
- IA / EE / TOK / CAS 核心项目阶段
- 15 / 25 / 45 / 60 分钟与自定专注时长、学习目标与科目、跨页面计时条、刷新恢复及取消后保留进度
- JSON 备份导出与恢复，兼容第一版备份

## 本地运行

```sh
python3 -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。站内使用 hash 路由与相对资源路径，可直接部署至 GitHub Pages 的 `/ib-tracker/` 子路径。

## GitHub Pages

本仓库的 Pages 使用 **Deploy from a branch → main → / (root)**。根目录 `index.html` 自动进入 `dist/` 应用，并保留页面路由与查询参数；`.nojekyll` 保持静态资源原样发布。推送 `main` 后由 GitHub 内置的 Pages 流程发布。

`.github/workflows/pages.yml` 独立执行 JavaScript 语法检查与回归测试，不重复创建 Pages 部署。

访问 https://hzagaming.github.io/ib-tracker/ 。发布设置参考 [GitHub 官方指南](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

GitHub Pages 发布的是应用代码。个人学习数据仍保存在使用者自己的浏览器中，不会提交到 GitHub。

## 数据

数据使用 `localStorage`，无登录、后端或跨设备同步。定期导出备份；导入将替换当前数据。移动到新域名（例如旧 Sites 地址迁往 GitHub Pages）时，在旧地址导出，再在新地址导入。不要把个人备份提交进公开仓库。

初始记录为空。课程清单提供常见课程和自定义名称，不替代学校选课要求或对应届次的官方学科指南。删除科目会删除关联知识点，其他记录保留并归入「综合 / 核心」。

## 检查

需要 Node.js 22 或更高版本：

```sh
npm ci --ignore-scripts
npm test
```

测试包含原有功能检查和 86 项 DOM 回归场景，覆盖存储失败后的回滚和重试、备份导入、损坏数据恢复、多标签页冲突、日期与字段校验、快捷键和计时器去重。DOM 测试使用 LinkeDOM（仅开发依赖），不替代真实浏览器视觉验收。

## 操作细节

右上角「快速记录」可添加任务、日志、成绩或核心项目。`Ctrl / ⌘ + K` 打开全局搜索；`Alt + N` 打开快速记录；列表页按 `/` 聚焦搜索框；对话框支持 `Escape` 关闭。笔记和反馈可以展开阅读。

手机下方提供总览、任务、学科、专注入口，其余页面通过「更多」进入。首次使用的引导会在添加科目并记录第一次学习后自动隐藏。

## 数据恢复与多标签页

存储失败时，修改不会显示为保存成功，并可保留表单重试。检测到其他标签页更新时，当前表单不会直接覆盖新记录；关闭表单后可载入最新记录。

若本地记录无法解析，应用保留原始存储，提供恢复文件导出、备份导入或经确认后重新开始。学习记录与计时状态分别保存；专注日志带有会话标记，避免计时器重置失败后重复记录同一时段。

## 学习工作室

「每周学习计划」支持按日安排日期、可选开始时间、时长和目标。完成后填写实际日期与实际时长，系统会保留原计划并生成一条关联日志；删除计划不会删除日志。

「复习中心」汇总到期、即将到期与全部知识点。根据自评选择 1 / 3 / 7 天后再看，这是可随时调整的个人安排。标记掌握较好的知识点仍会按安排再次出现；手动将知识点设为「已掌握」可停止此自动安排。

「学习资料库」支持 HTTP / HTTPS 链接与纯笔记，不自动抓取外部网页。工作卡由使用者主动收藏后保存到自己的资料中，没有预填的个人学习记录。

## 编辑与构建

`src/focus.js` 包含专注计时与记录衔接，`src/experience.js` 包含导航、任务操作与学习日程，`src/progress.js` 包含考试冲刺与周复盘，`src/insights.js` 包含错题、分析与搜索，`src/study.js` 包含计划、复习与资料库，`src/app.js` 包含基础记录与界面。修改后运行：

```sh
npm run build
npm test
```

`dist/app.js` 为已提交的单文件产物，避免旧缓存页面只加载到部分功能模块。测试会检查产物与源码一致。样式与 HTML 入口位于 `dist/`。

## 错题、分析与搜索

错题本支持按科目与状态筛选，订正默认折叠，便于先独立思考。记录「还需巩固」会安排三天后重做；选择独立完成后标记为已掌握。由错题生成的未完成复习任务会复用已有记录，避免重复。

分析只统计所选期间及今天以前的学习日志；最长连续学习日指所选期间内的最长连续记录，不将学习时长当作掌握程度。同一天多次测评以最后录入的记录作为最近一次。

全局搜索在本浏览器中执行，支持多个关键词和记录类型，不发送学习内容到外部搜索服务。每次先展示 60 条结果，可继续加载。

未保存的个人设置会在其他标签页更新时保留，离开页面时会提示确认。

## 考试冲刺与每周复盘

「考试冲刺」保存的是你自己填写的测评安排，不提供官方考试时间表。三步准备任务分别围绕范围整理、练习与最后检查；早于今天的阶段从今天开始，已有任务保留原安排，不重复创建。录入考试成绩会更新同一份关联成绩并将考试标记为已完成；删除考试不会删除已有任务和成绩。

「每周复盘」每周保留一份可编辑记录，以周一作为起点。页面汇总所选周截至今天的实际学习与复习次数，任务统计按截止日期归属。收获、卡点、方法调整与下一步均由自己填写，下一步可生成一项关联任务。

首页可直接进入最近考试和本周复盘，月历包含已录入的考试日期。旧备份会自动补齐新增集合。备份导入上限为 20MB，实际能否保存仍受当前浏览器可用空间影响。

设置页的未保存草稿会在快速记录、保存其他内容后保留。成功提交过的对话框会忽略重复提交事件。

## 黑白界面

全站使用黑、白与中性灰，包括桌面及手机导航、学习卡片、图表、日历、表单、提示与入口页。当前项使用黑底白字；逾期、完成与复习状态保留文字、图标和边框区分。输入焦点、复选框与浏览器主题色也采用中性色。

样式直接使用中性色值，无灰度滤镜。主要正文与辅助文字使用高对比度配色，分析热力图由浅至深表示投入量。

## 工作台操作优化

导航分为「开始学习」「学科与复习」「进度与成果」「项目与设置」，并显示待办、到期复习和近七天待考数量。

任务行的「⋯」可编辑、改到明天、安排学习、复制或删除。复制会创建一项独立的未完成任务；从任务安排学习会带入科目、标题与笔记，完成计划后仍可单独处理任务状态。

任务页支持截止日期 / 优先级排序、批量完成、批量把待办改到明天。筛选改变时，隐藏结果会移出选择；已完成任务的历史日期不会被批量改期。批量修改支持撤销，存储失败时保留选择以便重试。另一标签页的数据载入后会清理旧撤销入口。

手机端更多菜单支持同页点击、点击外部和 Escape 关闭，页面切换会回到顶部。跳转到主要内容不会切换当前页面。学习日志、成绩与任务的局部搜索包含笔记，空结果提供清除筛选入口。

## 统一学习日程

「学习日程」将任务、学习计划、考试与核心项目放在一起，可按科目、类型和待完成状态筛选。月历选择日期后，下方显示当天完整清单，可直接编辑原记录或完成学习计划并记录实际时间。

手机端使用紧凑七列月历；「日程清单」按日期展开整月安排。按日添加会带入所选日期与科目。键盘支持方向键、Home / End、Page Up / Down，跨月时自动处理月末与闰年。

首页到期复习与复习中心采用相同规则，已安排再次回顾的「已掌握」知识点仍会准时出现。首页和学科累计学习仅计算截至今天的日志，与学习分析保持一致。

## 专注与学习日志

任务的「⋯ → 开始专注」和学科工作台可以带入学习目标、科目及任务说明。专注支持四种常用时长，也可设置 1–480 分钟；开始后锁定本次目标与时长，暂停后可继续。

切到其他页面仍会计时，顶部计时条支持暂停、继续和记录。记录时自动带入本次目标、科目、开始日期与已专注的完整分钟数，可补充收获。保存后保留目标与所选时长，便于开始下一段；任务的完成状态由自己单独确认。跨午夜时默认使用本次开始日期，可在记录前调整。

重新开始或切换目标前，会确认是否放弃未记录的计时。另一个标签页更新了计时后，会检查最新状态，防止旧页面覆盖新计时；打开的日志草稿仍保留，但需关闭后重新确认计时再保存。每段专注带有独立标记，保存失败可重试，已记录的同一会话不会再次新增日志。

专注页汇总今天已保存的专注记录。尚未开始的目标与时长草稿，在快速记录或普通页面重绘后保留；刷新前可通过离开输入框保存有效设置。
